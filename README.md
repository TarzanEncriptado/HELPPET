# Help Pet – PET Fronteira (UFMS)

## 📌 Sobre o projeto
O **Help Pet** é um site desenvolvido pelo **PET Fronteira da UFMS** com o objetivo de **divulgar projetos, atividades e ações do grupo**, além de fornecer informações úteis para a comunidade acadêmica e externa.  
O projeto busca aproximar **ensino, pesquisa e extensão**, seguindo a filosofia do Programa de Educação Tutorial (PET).

---

## 🚀 Funcionalidades principais
- 📖 Apresentação dos projetos em andamento do PET Fronteira.  
- 📰 Divulgação de eventos, minicursos e oficinas.  
- 🧑‍🎓 Informações sobre como participar do PET.  
- 💬 Depoimentos e experiências de petianos.  
- 📞 Contato e informações institucionais da UFMS.  

---

## 🛠️ Tecnologias utilizadas
- **Frontend:** HTML5, CSS3, JavaScript  
- **Frameworks:** Bootstrap / Vue (caso use)  
- **Backend (se houver):** PHP / Laravel / CodeIgniter  
- **Outros recursos:** Owl Carousel, Bootstrap Icons
